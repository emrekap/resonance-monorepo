# packages/ml-client

Typed TypeScript client for the **Python ML service** — the typesafety seam across the polyglot boundary.

Generated from `apps/ml`'s **OpenAPI** spec (e.g. `openapi-typescript` / `orval`) and consumed by
[`apps/api`](../../apps/api) so Bun → Python calls are typed without hand-written `fetch`.

Regenerate whenever the ML service's API changes — don't hand-edit.
